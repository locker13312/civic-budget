# Запускати перевірки через npm-скрипти без Makefile

## Контекст і проблема

ADR-0004 зробив make-цілі єдиним джерелом команд для людини, хуків і CI.
У проєкті на Node.js кожна make-ціль лише викликала npm-скрипт з тією ж
назвою, а на Windows make доводилось ставити окремо. DoD курсу (повна
версія з AI, §5) прямо каже: для Node.js достатньо `npm run …`, окремий
Makefile не потрібен.

## Розглянуті варіанти

* npm-скрипти як єдине джерело команд, Makefile прибрати
* Лишити Makefile як обгортку над npm-скриптами

## Рішення

Обрано: «npm-скрипти як єдине джерело команд, Makefile прибрати», бо
обгортка не додавала жодної перевірки, а лише ще одну залежність (make) і
другу назву для кожної команди. Решта ADR-0004 лишається: хуки перевіряють
знімок коміту, CI повторює ту саму команду (`npm run check`).

### Наслідки

* Добре, бо на Windows потрібні лише Node.js і Git for Windows.
* Добре, бо команда в DEFENSE, хуку і CI одна: `npm run check`.
* Погано, бо `npm run check` описано ланцюжком `&&` в одному рядку
  `package.json`, і його гірше читати, ніж Makefile.

### Підтвердження

Тести хуків (AC-1.2…AC-1.4) проходять без make; `npm run docs` перевіряє,
що кожен `npm run x` у критеріях існує в `package.json`.

## Плюси й мінуси варіантів

### Лишити Makefile як обгортку

* Добре, бо `make <ціль>` збігається з формулюванням шаблону DEFENSE.
* Погано, бо дублює кожну назву і вимагає make на Windows.
