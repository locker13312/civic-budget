# Використовувати Python 3.13, FastAPI і uv

## Контекст і проблема

Потрібен стек для вебсервісу з БД, який підтримує суворі перевірки (типи,
лінтер, межі модулів) і швидко збирається в CI.

## Розглянуті варіанти

* Python 3.13 + FastAPI + uv
* Python + Django
* TypeScript + NestJS

## Рішення

Обрано: «Python 3.13 + FastAPI + uv», бо FastAPI не нав'язує структуру
проєкту (а ми будуємо свою, модульну), uv дає відтворюване оточення з
`uv.lock` за секунди, а для Python є інструмент перевірки меж імпортів.

### Наслідки

* Добре, бо ruff, mypy і pytest покривають формат, лінтер, типи і тести без
  важких налаштувань.
* Погано, бо типи в Python перевіряються лише статично: без `mypy --strict`
  у конвеєрі вони нічого не гарантують.

### Підтвердження

`uv sync --frozen` у `make setup` падає, якщо `uv.lock` не відповідає
`pyproject.toml`; `make types` запускає mypy у суворому режимі.

## Плюси й мінуси варіантів

### Python + Django

* Добре, бо адмінка і ORM з коробки.
* Погано, бо Django диктує структуру застосунків і моделей, яка конфліктує з
  модулями, що володіють своїми даними.

### TypeScript + NestJS

* Добре, бо типи перевіряються компілятором.
* Погано, бо модульність NestJS тримається на DI-контейнері, а не на
  перевірці імпортів, і я знаю цей стек гірше.
