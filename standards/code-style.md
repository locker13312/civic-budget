# Стандарт: стиль коду

JavaScript (ESM) на Node.js 22, типи в JSDoc. Стиль не обговорюємо на
рев'ю: усе, що можна, вирішує інструмент. Налаштування: `.prettierrc.json`,
`eslint.config.js`, `tsconfig.json`.

## Форматування

Prettier: одинарні лапки, крапка з комою, ширина рядка 90. Ручне
вирівнювання пробілами заборонене: форматтер його однаково прибере.

## Лінтер

ESLint 9 (flat config):

| Набір | Навіщо |
|---|---|
| `@eslint/js` recommended | базові помилки, невикористані змінні, недосяжний код |
| `eslint-plugin-jsdoc` | JSDoc коректний і відповідає параметрам функції |
| власні правила | `eqeqeq`, `prefer-const`, `no-var`, `curly`: менше місць для помилки |

## Типи

Код лишається JavaScript, а типи пишемо в JSDoc (`@param`, `@returns`,
`@typedef`). `tsc --noEmit` з `checkJs` і `strict` перевіряє `src`, `test` і
`scripts`. `@ts-ignore` заборонено; `@ts-expect-error` лише з коментарем,
чому.

## Структура

- ESM: `"type": "module"`, у відносних імпортах розширення `.js`
  обов'язкове.
- Ідентифікатори англійською, тексти для людей (повідомлення, документи)
  українською.
- Модуль системи це тека `src/<модуль>/` з `index.js`; межі описані в
  [spec.md](../spec.md).
- Доменні правила пишемо чистими функціями: вхід через аргументи, без
  глобального стану і без поточного часу всередині. Доменні об'єкти
  заморожені (`Object.freeze`).

## Залежності

- Пакет додається в тому ж коміті, що й перший `import` з нього. «Наперед,
  на наступне завдання» не додаємо (аудит Завдання 1, пункт 2).
- Те, що код імпортує, оголошено в `package.json` явно, навіть якщо воно
  вже приходить транзитивно.
- Експорт з `index.js` модуля існує, лише якщо його хтось імпортує: мертвий
  публічний API ховає, чим модуль насправді є.

Перевіряє `npm run deps` (knip).

## Коментарі

Коротко, з малої літери, лише там, де код сам не пояснює «чому». Без рамок
і декоративних роздільників.

## Тести

`node:test` без сторонніх бібліотек. Назва тесту описує поведінку:
`голос відхиляється, коли вичерпано ліміт`. Тест, що перевіряє критерій
прийняття, має в назві `[AC-N.k]`. Smoke-тести лежать у `test/smoke/`.
