# Стандарт: стиль коду

Python 3.13. Стиль не обговорюємо на рев'ю: усе, що можна, вирішує
інструмент. Налаштування в `pyproject.toml`.

## Форматування

`ruff format`, довжина рядка 88. Ручне вирівнювання пробілами заборонене:
форматтер його однаково прибере.

## Лінтер

`ruff check` з наборами правил:

| Набір | Навіщо |
|---|---|
| E, W, F | базові помилки і невикористані імена |
| I | порядок імпортів, щоб diff не шумів |
| B | типові баги (змінювані значення за замовчуванням тощо) |
| UP | сучасний синтаксис Python 3.13 |
| SIM, C4 | спрощення виразів |
| N | імена за PEP 8 |
| PT | стиль pytest |
| RUF | решта корисних правил ruff |

Вимкнено RUF001–RUF003: вони вважають українські літери «схожими на
латиницю» і падають на кожному рядку з українським текстом.

## Типи

`mypy --strict` для `src`, `tests` і `scripts`. `Any` і `type: ignore`
потребують коментаря з причиною.

## Структура

- Ідентифікатори англійською, тексти для людей (повідомлення, документи)
  українською.
- Модуль системи це пакет у `src/civic_budget/`; межі описані в
  [spec.md](../spec.md).
- Доменні правила пишемо чистими функціями: вхід через аргументи, без
  глобального стану і без поточного часу всередині.

## Коментарі

Коротко, з малої літери, лише там, де код сам не пояснює «чому». Без рамок
і декоративних роздільників.

## Тести

Ім'я тесту описує поведінку: `test_vote_rejected_when_limit_reached`.
Тест, що перевіряє критерій прийняття, має маркер `@pytest.mark.ac("AC-N.k")`.
Smoke-тести мають маркер `smoke`.
