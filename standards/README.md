# Інженерні стандарти проєкту

Стандарти діють на весь курс. Кожен має розділ «Як перевіряється»: правило,
яке можна перевірити автоматично, перевіряє конвеєр (`make check`, git-хуки,
CI), а не пам'ять автора. Решту перевіряє рев'ю за чеклистом DoD.

| Стандарт | Про що |
|---|---|
| [spec-format.md](spec-format.md) | як пишемо spec системи й spec інкременту, формат критеріїв прийняття |
| [adr.md](adr.md) | коли і як фіксуємо рішення (MADR) |
| [definition-of-done.md](definition-of-done.md) | коли завдання вважається готовим |
| [checks.md](checks.md) | перелік перевірок: що, чим, на якому етапі |
| [code-style.md](code-style.md) | стиль Python-коду і чому саме такий |

Шаблони: [templates/](templates/).

## Як змінюється стандарт

Стандарт змінюється окремим комітом з префіксом `standards:`. Якщо зміна
послаблює перевірку (вимикає правило, піднімає ліміт), у тому ж PR потрібен
ADR з причиною. Зміна, знайдена аудитом, посилається на пункт аудиту.
